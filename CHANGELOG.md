# Changelog

## 0.1.0

First release.

- Technologies from HTTP banners, cookies, TLS, HTML, links, JavaScript, 404 page and robots.txt, with version and evidence.
- `-a 3`: known paths and source maps. `-b` / `-p`: TCP service banners.
- `-l`: internal links, API endpoints, subdomains and third-party hosts.
- Terminal, JSON, CSV and text output.
